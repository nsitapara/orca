Pilot across machines

Pilot Machine Setup

Set up the Mac mini, a Debian box and an Arch box so one Pilot window shows every machine's Inbox, Running, Automations and Activity. Every script takes --dry-run and is safe to re-run. Your ticks and names stay in this browser.

Machine names

runs_on matches the name exactly, ignoring case and surrounding spaces: "Mac-mini" isn't "Mac mini". The SSH host is only used if you copy pilotcli over by hand.

Full guide, with what each script does, updating and uninstalling: docs/machine-setup.md
